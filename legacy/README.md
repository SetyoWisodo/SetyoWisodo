# Legacy (superseded) book pipeline

> ⚠️ **Not for publication.** These files are kept only for history.

This folder contains the first, auto-generated version of the book
(`gen_book*.py` → `book*.md` → `render_book*.py` → `Surviving_the_Future*.pdf`, 374 pages each).
An audit found that the text was mostly repeated filler: only about 17% of the sentences were unique,
and the footnotes attributed invented quotations to real scientists, citing a book that does not exist.

The book was rewritten from scratch with verified sources and a professional layout.
See [`../book/`](../book/README.md).
