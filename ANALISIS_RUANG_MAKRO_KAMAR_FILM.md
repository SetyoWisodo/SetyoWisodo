### 2.3 Hal yang perlu hati-hati

- **Akurasi.** Banyak judul menyentuh konspirasi (Area 51, Anunnaki, reinkarnasi). Format ini mudah bergeser ke misinformasi. Jika ditiru, setiap klaim sejarah harus dicek ke sumber primer.
- **Hak cipta footage.** Disclaimer channel menyatakan video dan gambar berasal dari sumber lain. Jangan meniru atau memotong konten ini untuk campaign berbayar tanpa izin.
- **Lisensi musik.** Kredit musik wajib diikuti (CC BY), jika dipakai.

## 3. Analisis Ruang Makro (terbatas)

**Yang bisa dibaca:** deskripsi channel menyebut geopolitik, ekonomi, filsafat, psikologi, dan geografi dunia, dengan "pendekatan visual dan analitis", dan fokus pada "kenapa" bukan "apa".

**Yang tidak bisa dibaca:** daftar video, durasi, views, pola judul, dan jadwal upload. Halaman video memberi error 401 di fetch.

**Implikasi:** Ruang Makro tampaknya berada di posisi berbeda dari Kamar Film. Kamar Film menjual **cerita dan misteri**. Ruang Makro, dari deskripsinya, menjual **penjelasan sistem** (ekonomi, geografi, geopolitik) dengan visual. Untuk membandingkan secara kuantitatif, perlu akses data: ScrapeCreators API atau ekspor manual dari YouTube Studio.

## 4. Bisakah Dibangun dengan Skill Repo?

### 4.1 Peta kebutuhan format → skill

| Kebutuhan format | Skill yang ada | Status |
|---|---|---|
| Riset topik dan outlier judul | `outlier-post-finder`, `trend-discovery` | Ada. Butuh API key ScrapeCreators |
| Membongkar struktur video panjang (hook, beat, transisi) | `transcript-intelligence` | Ada. Butuh transkrip |
| Baca komentar untuk ide episode berikutnya | `comment-mining` | Ada. Butuh API key |
| Analisis channel pesaing (jadwal, format, durasi, pilar) | `competitor-social-research`, `creator-profile-teardown` | Ada |
| Pecah 1 video panjang jadi Shorts, carousel, thread, WA | `content-repurposing` | Ada |
| Diagram sejarah / alur sebab-akibat geopolitik (gaya Ruang Makro) | `hairline-create`, `hairline-adopt`, `anatomy-reveal` | Ada. Cocok untuk visual analitis |
| Animasi transisi dan teks | `motion-design`, `motion` | Ada |
| Model 3D (globe, peta, objek) | `blender-download-artifacts`, `blender-knowledge-refresh` | Ada. Butuh Blender terpasang |
| Musik dan efek suara lisensi bebas | Openverse sound (dari pipeline awal) | Ada |
| Iklan dan distribusi Shorts/YouTube | `ads-youtube`, `ads-tiktok`, `ads-meta` | Ada |
| Analisis performa setelah upload | `ads-report`, `ads-monitor` | Ada (untuk iklan). Analitik organik belum ada skill khusus |
| **Penulisan naskah narasi 30–60 menit** | **Tidak ada skill khusus** | Gap. Bisa dibantu model bahasa, tetapi tidak ada template di repo |
| **Pengecekan fakta dan sumber primer** | **Tidak ada** | Gap penting, terutama untuk sejarah dan konspirasi |
| **Sourcing footage / arsip dengan lisensi** | **Tidak ada** | Gap. Perlu aturan hak cipta |
| **Narasi suara (voiceover)** | `generate_speech` di tools agent, belum jadi skill repo | Bisa dipakai, tetapi perlu persetujuan suara dan disclosure |
| **Editing video (cut, B-roll, subtitle, render)** | **Tidak ada** | Gap. Perlu tool eksternal (mis. ffmpeg, editor) |

### 4.2 Jawaban singkat

**Bisa dibangun:** sistem produksinya. Riset topik, bongkar struktur, analisis komentar, rencana episode, pecah ke Shorts, visual diagram, animasi, dan analisis performa sudah bisa dibantu skill repo, dengan syarat API key ScrapeCreators tersedia.

**Belum bisa:** produksi videonya secara penuh. Dua hal yang tidak bisa digantikan skill yang ada: (1) **riset dan penulisan naskah** yang akurat dan orisinal, dan (2) **editing dan sourcing footage**. Ada juga gap pengecekan fakta yang harus ditambahkan sebagai skill atau langkah manual.

**Yang paling cocok dengan repo:** versi Ruang Makro (analisis sistem + visual diagram + Blender), karena skill visual repo (hairline, anatomy-reveal, Blender, motion) sudah cocok dengan gaya "visual dan analitis".

## 5. Hubungan dengan Studio Anomali v2 (Clipper)

- Video panjang Kamar Film atau Ruang Makro bisa menjadi **sumber klip** untuk model clipper di `PROJECT_STUDIO_ANOMALI_v2_NASIONAL_CLIPPER.md`. Namun, **perlu izin tertulis** dari pemilik channel. Disclaimer hak cipta Kamar Film dan kebijakan klipping marketplace tidak mengizinkan pemotongan tanpa izin.
- Format "Understanding X in N minutes" dan judul berbahasa Inggris bisa dipakai sebagai template judul untuk klip UMKM atau edukasi produk, dengan topik yang relevan dan akurat.
- Versi "Ruang Makro untuk UMKM" (analisis pasar sederhana + visual diagram) adalah format yang bisa dikembangkan sebagai produk konten edukasi bagi UMKM.

## 6. Rekomendasi Langkah Berikutnya

1. **Aktifkan ScrapeCreators** (`SCRAPECREATORS_API_KEY`) untuk membaca data Ruang Makro (judul, views, durasi, jadwal) dan Kamar Film secara lengkap. Tanpa ini, analisis kuantitatif tidak mungkin.
2. **Ambil 10 video teratas** masing-masing channel, lalu jalankan `transcript-intelligence` untuk memetakan struktur hook dan beat.
3. **Tambah 2 skill baru** ke repo: (a) `script-long-form` untuk naskah narasi dengan daftar klaim yang harus dicek, dan (b) `fact-check-sources` untuk memeriksa klaim ke sumber primer.
4. **Prototipe 1 episode** Ruang Makro-style: 8 menit, 3 diagram hairline, 1 motion transition, 1 globe Blender. Ukur retensi setelah upload.
5. **Tanyakan izin** ke kedua channel sebelum memakai konten mereka sebagai klip.
