### 🧑‍💻 Tentang Saya (About Me)

Halo! Saya **Setyo Wisodo**, seorang profesional yang menggabungkan keahlian teknis dalam **Pengembangan AI**, visi strategis **Product Management**, serta eksekusi **Pemasaran (Marketing)** berbasis data untuk menciptakan produk digital yang inovatif, relevan dengan kebutuhan pasar, dan berdampak nyata.

- 🤖 **Pengembangan AI:** Merancang dan mengintegrasikan solusi *Artificial Intelligence*, *Generative AI / LLM*, serta otomasi cerdas ke dalam produk nyata.
- 📋 **Product Management:** Mengelola siklus hidup produk dari riset pengguna, perumusan strategi & *roadmap*, hingga peluncuran produk (*end-to-end execution*).
- 📊 **Pemasaran & Pertumbuhan (*Growth*):** Menyusun strategi *Go-To-Market (GTM)*, akuisisi pengguna, *digital marketing*, dan optimasi pertumbuhan bisnis.
- 👯 **Terbuka untuk kolaborasi:** Proyek inovasi AI, pengembangan produk *startup*/digital, dan strategi pertumbuhan pasar.
- 📍 **Lokasi:** Indonesia 🇮🇩

### 🎃 Pumpkin Terminal — Desk Trading 6 Agen (Paper Trading)

Jawaban teknis atas thread viral "$80 → $5.432 dalam semalam". Enam agen
(**Scout → Filter → Analyst → Sniper → Guard → Scribe**) memindai pair Solana,
menolak ~99% token karena aturan risiko, dan mencatat setiap keputusan —
**tanpa wallet dan tanpa order on-chain**.

Yang menarik justru hasilnya: dengan pipeline lengkap di pasar simulasi yang ramah,
median **+174%**; tanpa keahlian sama sekali (filter dilewati, skor acak),
median **−46%** dan habis di fee 5,5% per round-trip. Klaim +6.690% di thread
berada jauh di luar ekor distribusi bahkan dari simulasi itu sendiri.

```bash
cd pumpkin-terminal && python run.py serve   # dashboard live
python run.py bench                          # uji jujur: strategi vs lempar panah
```

Kode, aturan filter/risiko, dan 25 test: [`pumpkin-terminal/`](pumpkin-terminal/README.md)
