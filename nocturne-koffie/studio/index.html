Tahap 01 · niche researchCeruk, audiens, tawaran

Kopi specialty dari Banyuwangi yang menyebut nama petani, desa, ketinggian, tanggal sangrai, dan kode batch — disangrai mingguan oleh Ais Coffee Roastery.

Bukan (pagar positioning)

  • bukan roastery — kami tidak menyangrai sendiri
  • bukan kopi susu kekinian / minuman siap minum
  • bukan grosir termurah — harga punya lantai (margin tier)
  • bukan brand oleh-oleh — kemasan bukan suvenir
  • bukan penjual alat seduh atau mesin espresso

Kenapa tidak 50 agent LLM 50 agent berarti 50 kali biaya token untuk pekerjaan yang sebagian besar berupa hitungan tetap (median, lift, ranking, pengecekan kata terlarang). Di sini semua itu jadi fungsi Python: 0 token per tahap, hasilnya bisa diulang dan diperiksa. Yang benar-benar butuh pertimbangan manusia — memilih sudut, menilai rasa, menghubungi orang — tetap di tangan Anda dan ditandai manual.
