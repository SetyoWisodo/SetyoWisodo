# Checklist Launch 14 Hari — Nocturne Koffie

Dua minggu sampai website + semua kanal siap menerima order. Estimasi total:
**±12 jam** kerja, tersebar. Kerjakan berurutan; jangan lompat ke iklan.

- [ ] Nomor WhatsApp Business aktif + profil lengkap + katalog 5 produk

- [ ] Ganti `whatsapp` di `data/catalog.json` dengan nomor asli

## Hari 3–4 — Website (2 jam)
- [ ] Deploy folder `nocturne-koffie/` (Netlify drop / GitHub Pages / Vercel)
- [ ] Cek di HP: semua tombol WhatsApp terkirim dengan pesan benar

## Hari 11–12 — Jaringan (1 jam)

- [ ] Kirim 15 pesan pertama (`B2B-1`)

## Hari 13 — Sistem (30 menit)

- [ ] Isi `05-kpi-tracker.csv` baris pertama
